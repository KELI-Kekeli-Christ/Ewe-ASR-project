Training and evaluation scripts for Ewe (and Mina) ASR. There is no README. The files that exist are `prepare_ewe_manifests.py`, `fine_tune_afrihubert_ewe_asr.py`, `whisper_v2_base_fused_bibletts_mina_v3.py`, `whisper_v3_base_fused_bibletts_v3.py`, `eval.py`, `eval_afrihubert.py`, and `eval_fair_mina_v3.py`. Run the script that matches the experiment. Each script is the entry point; there is no shared launcher.
